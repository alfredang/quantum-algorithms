# Lab 01 — Linear Algebra for Quantum Mechanics in Python

**Topic 1:** Quantum Physics Fundamentals  
**Maps to:** LO1 — Design mathematical models required for quantum computing applications

Work with the mathematical objects every quantum algorithm is built from: state vectors, inner and outer products, unitary and Hermitian operators, eigenvalues and tensor products — all in NumPy.

## What you'll build

A Python notebook that verifies unitarity and Hermiticity, computes eigenvalues/eigenvectors, and builds two-qubit states with the tensor product.

**Tools:** Python 3.13, NumPy, Google Colab / VS Code

## Files

- `main.py` — Python implementation

## Run

```bash
python labs/lab01/main.py
```

## Test it

H-dagger H equals the identity, X and Z return real eigenvalues +1 and -1, the Born-rule probability of measuring 0 in |+> is 0.5, and the tensor product produces a 4-component two-qubit state.
